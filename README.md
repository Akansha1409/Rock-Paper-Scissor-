# ✂️🪨📄 Rock Paper Scissors Game

A **fun and interactive Rock-Paper-Scissors game** built with **HTML, CSS, and JavaScript**.  
Play against the computer and test your luck and strategy!  

---

## 🎮 How to Play

1. Select one of the three options: **Rock**, **Paper**, or **Scissors**.  
2. The computer randomly selects its option at the same time.  
3. The winner is determined by the rules:  
   - ✊ **Rock** beats ✌️ **Scissors**  
   - ✌️ **Scissors** beats 📄 **Paper**  
   - 📄 **Paper** beats ✊ **Rock**  
4. Keep score and try to beat the computer!
